Install Smart Connect for Linux

Pair your Motorola phone with your Linux desktop for notifications, clipboard sync, app streaming, wireless display, and shared mouse control. Setup takes about 10 minutes.

Reading this on your phone? Open this page on your Linux PC so you can copy commands straight into the terminal.

Before you start

  • A PC running Fedora, Ubuntu, Debian, or Arch Linux, with sudo access.
  • Your Motorola phone with the stock Smart Connect app. Nothing on the phone needs to be changed.
  • The PC and the phone on the same Wi-Fi network.

Prefer to do it yourself? Start at step 1.

1. Install prerequisites

This installs the build tools (including Rust), the GTK4 and GStreamer libraries, and the tools for network discovery, Bluetooth, and clipboard sync.

Terminal · Fedora 
sudo dnf install -y \
  git gcc pkgconf-pkg-config rust cargo dbus-devel wayland-devel \
  avahi avahi-tools bluez wl-clipboard NetworkManager fuse3 \
  gstreamer1-devel gstreamer1-plugins-base-devel gstreamer1-plugins-bad-free-devel \
  gstreamer1-plugins-good gstreamer1-plugins-bad-free libnice-gstreamer1 \
  gtk4-devel libadwaita-devel
Terminal · Ubuntu / Debian
sudo apt update && sudo apt install -y \
  git build-essential pkg-config cargo rustc libdbus-1-dev libwayland-dev \
  avahi-daemon avahi-utils bluez wl-clipboard network-manager fuse3 \
  libgstreamer1.0-dev libgstreamer-plugins-base1.0-dev libgstreamer-plugins-bad1.0-dev \
  gstreamer1.0-plugins-base gstreamer1.0-plugins-good gstreamer1.0-plugins-bad \
  gstreamer1.0-gl gstreamer1.0-nice gstreamer1.0-libav \
  libgtk-4-dev libadwaita-1-dev
Terminal · Arch Linux 
sudo pacman -S --needed \
  git base-devel pkgconf rust avahi bluez dbus wl-clipboard fuse3 \
  gstreamer gst-plugins-base gst-plugins-good gst-plugins-bad libnice gst-libav \
  gtk4 libadwaita

Start network discovery and Bluetooth

Avahi lets your phone find this PC on Wi-Fi without typing an IP address.

Terminal
sudo systemctl enable --now avahi-daemon bluetooth

2. Install from GitHub

The installer builds everything, copies it to ~/.local/bin, adds an app launcher, and starts the background service. The first build compiles Rust code and can take a few minutes.

Terminal
git clone https://github.com/Lalitmukesh69/smartconnect-linux-but-better.git
cd smartconnect-linux-but-better
./packaging/install.sh --enable

Advanced: download only the prebuilt app window

This is not a full install. smartconnect-gui is only the app window. Pairing, discovery, and streaming run in the smartconnectd service, which the installer above sets up. Use this option only if you already have the service.

Terminal · download, verify, make executable
curl -fsSL -o ~/.local/bin/smartconnect-gui \
  https://github.com/Lalitmukesh69/smartconnect-linux-but-better/releases/download/v0.2.0/smartconnect-gui
echo "375b657b5a308ee571c4814aae9a308bc21b72c42cfc535db4fca64150278827  $HOME/.local/bin/smartconnect-gui" | sha256sum -c -
chmod +x ~/.local/bin/smartconnect-gui

The second command should print OK. If it doesn't, delete the file and download it again.

3. Open the firewall

Smart Connect uses TCP port 52020 (an encrypted TLS WebSocket) for pairing and streaming, and mDNS for discovery. Without these rules your phone can't connect. Fedora uses firewalld; Ubuntu and Debian use ufw. On Arch, use whichever you have installed.

Terminal · firewalld 
sudo firewall-cmd --permanent --add-port=52020/tcp
sudo firewall-cmd --permanent --add-service=mdns
sudo firewall-cmd --reload
Terminal · ufw
sudo ufw allow 52020/tcp comment 'Smart Connect WebSocket'
sudo ufw allow 5353/udp comment 'mDNS discovery'
sudo ufw reload

firewalld applies these rules to the default zone. If your Wi-Fi uses another zone, run firewall-cmd --get-active-zones and add --zone=<name> to each command.

4. Verify and launch

Check that the background service is running. Look for Active: active (running), then press q to leave the status screen.

Terminal
systemctl --user status smartconnectd

Then open Smart Connect from your app launcher, or start it from the terminal:

Terminal
smartconnect-gui &

Not running, or the command isn't found? See Troubleshooting.

5. Pair your phone

Make sure the PC and phone are on the same Wi-Fi network, then:

  1. On the PC, click Pair new phone…. A QR code appears.
  2. On the phone, open the stock Smart Connect app, tap + (or Add device), choose Scan QR code, and point the camera at the PC screen.
  3. Wait a moment. The dialog closes and the main window shows your phone's name, battery level, signal, and Wi-Fi status.

What you can do

Clipboard sync
Copy on one device and paste on the other. Needs wl-clipboard.
Notifications
Phone notifications appear as desktop notifications.
App streaming and wireless display
Show your phone screen or individual phone apps on the PC.
Shared mouse and keyboard
Move the cursor between your PC and phone.
Webcam
Use your phone's camera as a webcam on Linux.
Command palette
Press Ctrl + K to search and open features.
Updates
Open the … menu and choose Check for Updates… to install new versions without the terminal.

Troubleshooting

My phone can't find the PC

Confirm both devices are on the same Wi-Fi network. Guest networks and some routers block devices from seeing each other (often called client or AP isolation), so use the main network. Then restart discovery and reload the firewall:

Terminal
sudo systemctl restart avahi-daemon
sudo firewall-cmd --reload

On Ubuntu or Debian, run sudo ufw reload instead of the second command.

Port 52020 is already in use

Restart the service instead of starting smartconnectd yourself.

Terminal
systemctl --user restart smartconnectd
The service isn't running

Read the service log to see why it stopped.

Terminal
journalctl --user -u smartconnectd -e
The build fails with a Rust version error

Your distribution's Rust may be too old. Install the current toolchain with rustup, open a new terminal, and run the installer again.

smartconnect-gui: command not found

Add ~/.local/bin to your PATH, then open a new terminal.

Terminal
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc

Using zsh? Replace ~/.bashrc with ~/.zshrc.

The app icon is missing from the launcher
Terminal
update-desktop-database ~/.local/share/applications
Clipboard sync isn't working

Check that wl-clipboard is installed. If the command isn't found, install the package from step 1.

Terminal
wl-copy --version

Uninstall or start fresh

Run this from the repository folder you cloned in step 2:

Terminal
./packaging/uninstall.sh
Remove it manually

This stops the service and deletes the program files and launchers.

Terminal
systemctl --user stop smartconnectd.service 2>/dev/null || true
systemctl --user disable smartconnectd.service 2>/dev/null || true
killall -9 smartconnectd smartconnect-gui 2>/dev/null || true
rm -f ~/.local/bin/smartconnect*
rm -f ~/.local/share/applications/dev.smartconnect.Linux.desktop
rm -f ~/.local/share/applications/dev.smartconnect.Display.desktop
rm -f ~/.config/systemd/user/smartconnectd.service
systemctl --user daemon-reload
update-desktop-database -q ~/.local/share/applications 2>/dev/null || true

Optional: forget this PC's pairing. This deletes the saved pairing keys, settings, and cache, so you'll need to pair again. Also remove the PC in the phone app under Settings > Connected Computers.

Terminal
rm -rf ~/.local/share/smartconnect-linux ~/.config/smartconnect-linux ~/.cache/smartconnect

Smart Connect for Linux · v0.2.0

Your Motorola phone, on your Linux desktop.

Connect your Motorola phone to a fresh Linux machine for notifications, bi-directional clipboard sync, app streaming, wireless display, and shared mouse control over local Wi-Fi. Completely native, with no phone-side modifications required.

~10 minutes setup Port 52020 (TLS WebSocket) + mDNS Stock phone app only
Motorola Phone · Paired
TLS 52020 · 5 GHz (1200 Mbps)

Shared Clipboard

Bi-directional Wayland clipboard sync active

Notification Relay

Phone alerts mirrored with action replies

Wireless Display

H.264 hardware stream to Linux desktop

Cross Control

Seamless mouse & keyboard flow between screens

Linux PC with Wi-Fi

Fedora, Ubuntu, Debian, or Arch Linux on the same Wi-Fi network as your phone.

Motorola Phone

Uses the stock Motorola Smart Connect app to scan the pairing QR code.

Prompt · Full install (Fedora) 
Install and set up "Smart Connect for Linux" (v0.2.0) on this Linux machine by running the exact commands below in order. Confirm before running sudo commands if needed, and stop to report any error.

1. Install prerequisites and Rust toolchain (Fedora):
sudo dnf install -y \
  git gcc pkgconf-pkg-config rust cargo dbus-devel wayland-devel \
  avahi avahi-tools bluez wl-clipboard NetworkManager fuse3 \
  gstreamer1-devel gstreamer1-plugins-base-devel gstreamer1-plugins-bad-free-devel \
  gstreamer1-plugins-good gstreamer1-plugins-bad-free libnice-gstreamer1 \
  gtk4-devel libadwaita-devel

2. Enable mDNS discovery and Bluetooth:
sudo systemctl enable --now avahi-daemon bluetooth

3. Clone and run the automated source installer:
git clone https://github.com/Lalitmukesh69/smartconnect-linux-but-better.git
cd smartconnect-linux-but-better
./packaging/install.sh --enable

4. Open TCP port 52020 (TLS WebSocket) and mDNS in firewalld:
firewall-cmd --get-active-zones
sudo firewall-cmd --permanent --add-port=52020/tcp
sudo firewall-cmd --permanent --add-service=mdns
sudo firewall-cmd --reload

5. Verify the systemd user service is active (running) and launch the GUI:
systemctl --user status smartconnectd
smartconnect-gui &

Once smartconnect-gui is open and smartconnectd is active (running), tell me I am ready to click "Pair new phone…" and scan the QR code from the Motorola Smart Connect app on my phone.
Prompt · Diagnose & fix Smart Connect 
Diagnose and fix my "Smart Connect for Linux" installation using these checks and fixes:

1. Verify the background service status:
systemctl --user status smartconnectd
- If port 52020 is already in use or the daemon is stuck, restart it with:
systemctl --user restart smartconnectd
(Do not run smartconnectd manually while the systemd user service is active.)

2. Check mDNS and firewall rules for port 52020/tcp and mDNS:
- On firewalld, reload rules with:
sudo firewall-cmd --reload
- Verify avahi-daemon is running and remind me to confirm my PC and Motorola phone are on the exact same Wi-Fi SSID.

3. Check clipboard sync dependency:
wl-copy --version
- Confirm wl-clipboard is installed and working.

4. Refresh the desktop launcher database if the app icon is missing:
update-desktop-database ~/.local/share/applications

Report what you found and what you fixed.
Prompt · Clean slate / uninstall 
Cleanly uninstall "Smart Connect for Linux" from this machine so we have a clean slate. Run these exact commands:

systemctl --user stop smartconnectd.service 2>/dev/null || true
systemctl --user disable smartconnectd.service 2>/dev/null || true
killall -9 smartconnectd smartconnect-gui 2>/dev/null || true
rm -f ~/.local/bin/smartconnect*
rm -f ~/.local/share/applications/dev.smartconnect.Linux.desktop
rm -f ~/.local/share/applications/dev.smartconnect.Display.desktop
rm -f ~/.config/systemd/user/smartconnectd.service
systemctl --user daemon-reload
update-desktop-database -q ~/.local/share/applications 2>/dev/null || true

Before deleting saved pairing credentials, ask me if I also want to remove them. If I say yes, run:
rm -rf ~/.local/share/smartconnect-linux ~/.config/smartconnect-linux ~/.cache/smartconnect
and remind me to remove this PC from the Motorola Smart Connect app on my phone under Settings > Connected Computers.

Install prerequisites & Rust

Install the Rust build toolchain, GTK4 and libadwaita UI libraries, GStreamer plugins for video streaming, Avahi for mDNS discovery, BlueZ, FUSE3, and Wayland clipboard utilities.

Installs Rust, Cargo, GTK4/libadwaita headers, GStreamer plugins, Avahi, BlueZ, FUSE3, and wl-clipboard via dnf.

Terminal · Fedora 
sudo dnf install -y \
  git gcc pkgconf-pkg-config rust cargo dbus-devel wayland-devel \
  avahi avahi-tools bluez wl-clipboard NetworkManager fuse3 \
  gstreamer1-devel gstreamer1-plugins-base-devel gstreamer1-plugins-bad-free-devel \
  gstreamer1-plugins-good gstreamer1-plugins-bad-free libnice-gstreamer1 \
  gtk4-devel libadwaita-devel

Refreshes apt repositories and installs the build toolchain, Cargo, Rustc, GTK4/libadwaita libraries, GStreamer video plugins, Avahi, BlueZ, FUSE3, and wl-clipboard.

Terminal · Ubuntu / Debian 
sudo apt update && sudo apt install -y \
  git build-essential pkg-config cargo rustc libdbus-1-dev libwayland-dev \
  avahi-daemon avahi-utils bluez wl-clipboard network-manager fuse3 \
  libgstreamer1.0-dev libgstreamer-plugins-base1.0-dev libgstreamer-plugins-bad1.0-dev \
  gstreamer1.0-plugins-base gstreamer1.0-plugins-good gstreamer1.0-plugins-bad \
  gstreamer1.0-gl gstreamer1.0-nice gstreamer1.0-libav \
  libgtk-4-dev libadwaita-1-dev

Installs the base development packages, Rust, GTK4, libadwaita, GStreamer plugins, Avahi, BlueZ, FUSE3, and wl-clipboard via pacman.

Terminal · Arch Linux 
sudo pacman -S --needed \
  git base-devel pkgconf rust avahi bluez dbus wl-clipboard fuse3 \
  gstreamer gst-plugins-base gst-plugins-good gst-plugins-bad libnice gst-libav \
  gtk4 libadwaita

Enable Avahi and Bluetooth services

Avahi provides local network discovery (mDNS) so your phone can detect your Linux machine automatically. Enable and start both services:

Terminal 
sudo systemctl enable --now avahi-daemon bluetooth

Open the firewall

Smart Connect requires incoming TCP port 52020 for the TLS WebSocket pairing and streaming session, plus UDP port 5353 for Avahi mDNS discovery.

Allow port 52020/tcp and the mdns service permanently, then reload rules:

Terminal · firewalld 
sudo firewall-cmd --permanent --add-port=52020/tcp
sudo firewall-cmd --permanent --add-service=mdns
sudo firewall-cmd --reload

Open port 52020/tcp and mDNS port 5353/udp in ufw:

Terminal · ufw 
sudo ufw allow 52020/tcp comment 'Smart Connect WebSocket'
sudo ufw allow 5353/udp comment 'mDNS discovery'
sudo ufw reload

Pair your phone

With both devices on the same Wi-Fi network, complete pairing in three steps:

  1. 1

    Open pairing modal

    In smartconnect-gui, click "Pair new phone…" to generate a local session QR code.

  2. 2

    Scan from phone

    Open the stock Smart Connect app on your Motorola phone, tap Scan QR code, and scan the PC screen.

  3. 3

    Connected

    TLS keys exchange instantly. Your phone connects and features activate automatically.

What you get

Native Linux desktop integrations communicating over encrypted local WebSocket:

  • Bi-directional Clipboard Sync

    Copies text and images seamlessly between Wayland/X11 and your phone via wl-clipboard.

  • Desktop Notification Relay

    Phone notifications appear as native desktop banners via org.freedesktop.Notifications with action replies.

  • Low-Latency Display & Apps

    Streams phone screens or standalone applications using GStreamer hardware H.264 decoding.

  • Cross Control

    Smooth mouse cursor and keyboard flow across phone and desktop monitors.

  • Webcam Streaming

    Use your phone's high-definition camera as a virtual V4L2 webcam on Linux.

  • Command Palette & Updater

    Spotlight launcher (Ctrl+K) for rapid navigation and built-in GitHub release updates.

Troubleshooting

Common setup questions and commands to resolve them:

Verify both devices are connected to the exact same Wi-Fi SSID and that mDNS discovery is enabled:

Terminal 
sudo systemctl restart avahi-daemon
sudo firewall-cmd --reload

Restart the user service rather than starting smartconnectd manually:

Terminal 
systemctl --user restart smartconnectd

Refresh the application database for your user profile:

Terminal 
update-desktop-database ~/.local/share/applications

Confirm wl-clipboard is installed by checking wl-copy:

Terminal 
wl-copy --version

Start fresh or uninstall

Run the uninstall script from your repository checkout:

Terminal · Uninstall 
./packaging/uninstall.sh

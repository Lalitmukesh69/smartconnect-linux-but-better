Installation Guide · v0.2.0

Install Smart Connect for Linux

Connect your Motorola phone to a fresh Linux desktop for notifications, clipboard sync, app streaming, wireless display, and mouse sharing over local Wi-Fi.

~10 minutes Port 52020 (TLS WebSocket) + mDNS Stock phone app only

Linux PC with Wi-Fi

Fedora, Ubuntu, Debian, or Arch Linux on the same Wi-Fi network as your phone.

Motorola phone

Uses the stock Motorola Smart Connect app to scan the pairing QR code.

About 10 minutes

Run it manually below or hand a single prompt to Claude Code or Antigravity.

No phone-side modifications are required. Smart Connect for Linux pairs natively with the stock Motorola Smart Connect app from your phone.

Your Linux distribution Syncs the AI agent prompt, Step 1 packages, and Step 3 firewall rules.

Let an AI agent install it for you

Copy one of the prompts below and paste it into Claude Code, Antigravity, or any terminal coding agent. It includes the exact repository, package names, port 52020 firewall rules, and verification checks so the agent runs the full setup without guessing.

Prompt · Full install (Fedora) 
Install and set up "Smart Connect for Linux" (v0.2.0) on this Linux machine by running the exact commands below in order. Confirm before running sudo commands if needed, and stop to report any error.

1. Install prerequisites (Fedora):
sudo dnf install -y \
  git gcc pkgconf-pkg-config dbus-devel wayland-devel \
  avahi avahi-tools bluez wl-clipboard NetworkManager fuse3 \
  gstreamer1-devel gstreamer1-plugins-base-devel gstreamer1-plugins-bad-free-devel \
  gstreamer1-plugins-good gstreamer1-plugins-bad-free libnice-gstreamer1 \
  gtk4-devel libadwaita-devel

2. Enable mDNS discovery and Bluetooth:
sudo systemctl enable --now avahi-daemon bluetooth

3. Clone and run the automated source installer:
git clone https://github.com/Lalitmukesh69/smartconnect-linux-but-better.git
cd smartconnect-linux-but-better
./packaging/install.sh --enable

4. Open TCP port 52020 (TLS WebSocket) and mDNS in firewalld:
firewall-cmd --get-active-zones
sudo firewall-cmd --permanent --add-port=52020/tcp
sudo firewall-cmd --permanent --add-service=mdns
sudo firewall-cmd --reload

5. Verify the systemd user service is active (running) and launch the GUI:
systemctl --user status smartconnectd
smartconnect-gui &

Once smartconnect-gui is open and smartconnectd is active (running), tell me I am ready to click "Pair new phone…" and scan the QR code from the Motorola Smart Connect app on my phone.

Switch your distribution above to automatically update the package and firewall commands inside this prompt. After the agent finishes, jump straight to Step 5: Pair your phone.

Prompt · Diagnose & fix Smart Connect 
Diagnose and fix my "Smart Connect for Linux" installation using these checks and fixes:

1. Verify the background service status:
systemctl --user status smartconnectd
- If port 52020 is already in use or the daemon is stuck, restart it with:
systemctl --user restart smartconnectd
(Do not run smartconnectd manually while the systemd user service is active.)

2. Check mDNS and firewall rules for port 52020/tcp and mDNS:
- On firewalld, reload rules with:
sudo firewall-cmd --reload
- Verify avahi-daemon is running and remind me to confirm my PC and Motorola phone are on the exact same Wi-Fi SSID.

3. Check clipboard sync dependency:
wl-copy --version
- Confirm wl-clipboard is installed and working.

4. Refresh the desktop launcher database if the app icon is missing:
update-desktop-database ~/.local/share/applications

Report what you found and what you fixed.
Prompt · Clean slate / uninstall 
Cleanly uninstall "Smart Connect for Linux" from this machine so we have a clean slate. Run these exact commands:

systemctl --user stop smartconnectd.service 2>/dev/null || true

rm -rf ~/.local/share/smartconnect-linux ~/.config/smartconnect-linux ~/.cache/smartconnect
and remind me to remove this PC from the Motorola Smart Connect app on my phone under Settings > Connected Computers.

Install prerequisites

Install the GTK4 and libadwaita UI libraries, GStreamer plugins for video mirroring, Avahi for local network discovery, BlueZ, FUSE3, and Wayland clipboard utilities.

Installs all required build tools, GTK4/libadwaita development headers, GStreamer plugins, Avahi, BlueZ, FUSE3, and wl-clipboard via dnf.

Terminal · Fedora 
sudo dnf install -y \
  git gcc pkgconf-pkg-config dbus-devel wayland-devel \
  avahi avahi-tools bluez wl-clipboard NetworkManager fuse3 \
  gstreamer1-devel gstreamer1-plugins-base-devel gstreamer1-plugins-bad-free-devel \
  gstreamer1-plugins-good gstreamer1-plugins-bad-free libnice-gstreamer1 \
  gtk4-devel libadwaita-devel

Refreshes apt repositories and installs the build toolchain, GTK4/libadwaita libraries, GStreamer video plugins, Avahi, BlueZ, FUSE3, and wl-clipboard.

Terminal · Ubuntu / Debian 
sudo apt update && sudo apt install -y \
  git build-essential pkg-config libdbus-1-dev libwayland-dev \
  avahi-daemon avahi-utils bluez wl-clipboard network-manager fuse3 \
  libgstreamer1.0-dev libgstreamer-plugins-base1.0-dev libgstreamer-plugins-bad1.0-dev \
  gstreamer1.0-plugins-base gstreamer1.0-plugins-good gstreamer1.0-plugins-bad \
  gstreamer1.0-gl gstreamer1.0-nice gstreamer1.0-libav \
  libgtk-4-dev libadwaita-1-dev

Installs the base development packages, Rust, GTK4, libadwaita, GStreamer plugins, Avahi, BlueZ, FUSE3, and wl-clipboard via pacman.

Terminal · Arch 
sudo pacman -S --needed \
  git base-devel pkgconf rust avahi bluez dbus wl-clipboard fuse3 \
  gstreamer gst-plugins-base gst-plugins-good gst-plugins-bad libnice gst-libav \
  gtk4 libadwaita

Enable Avahi and Bluetooth

Avahi provides mDNS discovery so your phone and PC can find each other automatically over Wi-Fi without manual IP configuration. Enable and start both services:

Terminal 
sudo systemctl enable --now avahi-daemon bluetooth

Install from GitHub

Building from source is recommended because the installer sets up every component automatically. A prebuilt GUI binary is also available if you want a quick download.

Clones the repository and runs ./packaging/install.sh --enable, which compiles all 8 binaries (smartconnectd, smartconnect-gui, mirror, display, webcam, files, crosscontrol, and fex), installs them to ~/.local/bin, adds the desktop launcher with hicolor icons, and starts the systemd user service.

Terminal 
git clone https://github.com/Lalitmukesh69/smartconnect-linux-but-better.git
cd smartconnect-linux-but-better
./packaging/install.sh --enable

Open the firewall

Smart Connect communicates locally over encrypted TLS WebSockets on TCP port 52020 and uses mDNS for device discovery. Allow both through your firewall so your phone can initiate the handshake.

Displays the active firewall zone attached to your Wi-Fi connection.

Terminal · firewalld 
firewall-cmd --get-active-zones

Permanently allows TCP port 52020 and the mdns service, then reloads firewalld rules.

Terminal · firewalld 
sudo firewall-cmd --permanent --add-port=52020/tcp
sudo firewall-cmd --permanent --add-service=mdns
sudo firewall-cmd --reload

Allows TCP port 52020 for Smart Connect WebSockets and UDP port 5353 for mDNS discovery, then reloads ufw.

Terminal · ufw 
sudo ufw allow 52020/tcp comment 'Smart Connect WebSocket'
sudo ufw allow 5353/udp comment 'mDNS discovery'
sudo ufw reload

Open the application

Press the Super key to open your application launcher, search for Smart Connect, and click the squircle icon. Alternatively, start the GUI in the background from your terminal:

Terminal 
smartconnect-gui &

Pair your phone

Make sure both your Linux PC and Motorola phone are connected to the same Wi-Fi SSID, then follow these three steps:

1. Click “Pair new phone…”

In the Smart Connect window on Linux, click Pair new phone… to display the QR code pairing dialog.

+ → Scan QR Code

2. Scan on your phone

Open the stock Smart Connect app on your Motorola phone, tap + (or Add device) → Scan QR Code, and point the camera at the screen.

motorola edge Battery · Signal · Wi-Fi

3. Connected

The dialog closes within a second and the main window shows your phone name (e.g. motorola edge), battery percentage with charging status, cellular signal bars, and Wi-Fi indicator.

Troubleshooting

Common setup issues and the commands to resolve them:

Reload firewalld rules and verify that both your PC and phone are connected to the exact same Wi-Fi SSID.

Terminal 
sudo firewall-cmd --reload

Restart the systemd user service instead of starting smartconnectd manually while the service is active.

Terminal 
systemctl --user restart smartconnectd

Refresh your user desktop entry cache so the Smart Connect launcher icon appears in search.

Terminal 
update-desktop-database ~/.local/share/applications

Make sure wl-clipboard is installed on your machine by checking wl-copy:

Terminal 
wl-copy --version

Start fresh or uninstall

Clear leftover builds, running services, desktop entries, and optional pairing data before reinstalling or removing Smart Connect.

Clean-slate and uninstall commands

Stops and disables smartconnectd.service, kills any stray daemon or GUI process, removes binaries, desktop launchers, and the systemd user unit, then reloads systemd and the desktop database:

Terminal 
systemctl --user stop smartconnectd.service 2>/dev/null || true
systemctl --user disable smartconnectd.service 2>/dev/null || true
killall -9 smartconnectd smartconnect-gui 2>/dev/null || true
rm -f ~/.local/bin/smartconnect*
rm -f ~/.local/share/applications/dev.smartconnect.Linux.desktop
rm -f ~/.local/share/applications/dev.smartconnect.Display.desktop
rm -f ~/.config/systemd/user/smartconnectd.service
systemctl --user daemon-reload
update-desktop-database -q ~/.local/share/applications 2>/dev/null || true

Optional — remove saved pairing credentials: Deletes local pairing keys, config, and cache so you can pair from scratch. Also remove this PC from the Motorola Smart Connect app on your phone under Settings > Connected Computers.

Terminal 
rm -rf ~/.local/share/smartconnect-linux ~/.config/smartconnect-linux ~/.cache/smartconnect

# GTK app: Apple Pro Dark Monochrome redesign (Phase 1 — Shell, Palette, Phone)

## What
Began a staged redesign of `smartconnect-gui` to follow an Apple Pro Dark Monochrome / Sidebar Split-View Bento aesthetic while keeping 100% real `smartconnectd` and helper state (no fabricated mock telemetry):

- **Design system ([`gui/src/theme.rs`](../gui/src/theme.rs)):** Enforces dark polarity (`adw::ColorScheme::ForceDark`), configures global **Helvetica** typography (`"Helvetica", "Nimbus Sans", "Liberation Sans", sans-serif` across `window.sc-root`, `.sc-dialog`, `popover`, `dialog`, `toast`, `adw` views, tabular numerals on metrics/tags via `font-feature-settings: "tnum" 1`, `gtk::Settings` `gtk-font-name` set to `Helvetica`, Cairo `select_font_face("Helvetica", ...)` in [`gui/src/crosscontrol.rs`](../gui/src/crosscontrol.rs), and bold spans in [`gui/src/display.rs`](../gui/src/display.rs) instead of monospace `<tt>`), registers CSS at `gtk::STYLE_PROVIDER_PRIORITY_USER + 50` scoped under `window.sc-root` and `.sc-dialog` (resetting `background-image`/`outline` and `menubutton > button` chrome so custom user desktop GTK themes cannot override pure-white active pills or primary CTAs), and overrides libadwaita CSS variables (`--window-bg-color: #050506`, `--sidebar-bg-color: #0A0A0C`, `--card-bg-color: #0E0E11`, `--accent-bg-color: #FFFFFF`, `--accent-fg-color: #050506`). Adds Bento surface rules (`.sc-bento`, `.sc-stat-tile`, `.sc-sidebar`, `.sc-nav-item.active` pure-white pill, `.sc-btn-primary`, `.sc-btn-secondary`, monochrome `.sc-seg-on`/`.sc-seg-off`, glowing `.sc-dot-online`, `.sc-kbd` keycaps, `.sc-avatar-frame`, `.sc-repo-row`) without GTK4-unsupported web CSS (`backdrop-filter`, CSS flex `gap`). Also provides a custom Cairo `brand_mark()` (stacked white icon), the `ModernIcon` stroke-vector renderer (`IconKind`, including `User`, `ExternalLink`, and `Refresh`), `format_display_path()` (`$HOME` → `~`), and monochrome status helpers.
- **Spotlight Command Palette, Endpoint Telemetry & About Developer ([`gui/src/palette.rs`](../gui/src/palette.rs)):**
  - `Ctrl+K` (or header / sidebar quick-command triggers) opens an `adw::Dialog` command palette searching navigation views, primary connect/mirror/mount/Cross-Control/pair/developer/preferences actions, shortcuts, and live streamed phone apps (`smartconnect-mirror --list-apps`), with keyboard navigation (`Up`/`Down`/`Enter`/`Esc`) that keeps typing focus inside the search entry.
  - **Endpoint Telemetry** dialog presents truthful endpoint specs (`phoneAddress`, `pcAddress`, hardware model, link status, battery/radio summary, cached app/icon counts, FUSE mount path/state, and shared folder path/state).
  - **About Developer** modal (`present_developer_dialog`, `win.developer`, reachable from the header User icon, Device popover, primary `app_menu`, Preferences → Help & About, and `Ctrl+K`) renders a seeded monochrome developer Bento (name, `@Lalitmukesh69` handle, bio, company/location, website/X/GitHub links, public repo/follower/following stat tiles, featured GitHub repositories) and asynchronously syncs live JSON + avatar from `https://api.github.com/users/Lalitmukesh69` and `/repos` into `$XDG_CACHE_HOME/smartconnect-linux/` (`developer-github.json`, `developer-avatar.png`) with offline cache fallback and a manual refresh button.
- **280 px Split-View Shell & Sticky Workspace Header ([`gui/src/window.rs`](../gui/src/window.rs)):**
  - Replaced top `AdwViewSwitcher` + `AdwViewSwitcherBar` with `AdwOverlaySplitView` (`280 px` pinned sidebar collapsing via `AdwBreakpoint` below `780sp`), housing the brand mark + `Ctrl+K` pill in `gtk::WindowHandle`, device endpoint switcher popover (`Rename Device…`, `System Telemetry…`, `Pair new phone…`, `Preferences…`, `Connect/Disconnect`, `Start service`), grouped `WORKSPACE` (`Phone`, `Apps`) and `CONTINUITY` (`Display`, `Files`, `Notifications`) nav buttons rendered with `ModernIcon` stroke vectors and live `Apps` / unread notification badges, plus footer telemetry summary and primary CTA.
  - Added a `56 px` sticky workspace `HeaderBar` (`title-widget` cleared so Adwaita never draws a centered duplicate title) showing sidebar collapse toggle when narrow, `<Device> / <View>` breadcrumb, concise status pill, `Command Ctrl+K`, Telemetry icon button, Connect/Disconnect CTA, and `MoreDots` menu trigger.
  - Raised default `WindowPrefs` size in [`gui/src/prefs.rs`](../gui/src/prefs.rs) from `920×760` to `1120×760` and added optional `deviceAlias` (`device_alias`) persisted locally in `gui.json`.
- **Phone Bento Overview (`PhonePage` in [`gui/src/window.rs`](../gui/src/window.rs)):**
  - Vertically and horizontally centered layout (`center_scroller`, max width `1020`) with Endpoint Identity Hero Bento showing proportional `62×92` live wallpaper thumbnail (or `ModernIcon::Smartphone` tile), link status pill, hardware model badge, inline local nickname rename editor (`IconKind::Edit` → `deviceAlias`), Mirror screen / Telemetry / Connect / Pair controls, and unread notifications shortcut.
  - Aligned 4-column Telemetry Bento grid (`Battery` with 5-segment progress bar, `Wi-Fi Link` with 4-bar signal meter, `Cellular` with 4-bar signal meter and bottom sublabel, `Bluetooth`) driven strictly by live/cached daemon data.
  - `Cross Control` quick-launch Bento (`IconKind::Mouse` inverted white icon box, active mode pills, edge anchor) linking straight into the Display studio.
  - Symmetrical 3-column `System Continuity` Bento row with `38×38` leading icon tiles wired to [`AppsPage`](../gui/src/apps.rs), [`FilesPage`](../gui/src/files.rs), and [`ShareSection`](../gui/src/share.rs) change callbacks (`Recent App Stream`, `Mount Location`, `Shared Directory`).

## Notes for Remaining Phases
- `Apps`, `Display / Cross Control`, `Files`, and `Notifications` page internals keep existing layouts inside the dark monochrome shell until Phases 2–5 restyle each page individually.

DESIGN.md — Apple Pro Monochrome Design SystemProduct: Smart Connect / Cross Control Desktop Companion (motorola edge 50 neo)Design Paradigm: Apple Pro Dark Mode · Pure Architectural Monochrome · Full-Bleed SaaS Workspace1. Design Philosophy & Core PrinciplesZero-Mockup Pure Application Interface:The application renders edge-to-edge (100vw × 100vh) as a native desktop workspace without decorative outer desktop wallpapers, floating window frames, macOS traffic-light chrome, or 3D phone bezel illustrations.Architectural Monochrome Discipline:Visual hierarchy is established strictly through luminance contrast, surface elevation, hairline 1px specular borders, and typographic scale rather than multi-colored accents.Pure White (#FFFFFF) is reserved exclusively for active selection states, primary actions, active toggles, and live continuity seams.Left-Sidebar Split-View Ergonomics:Replacing the legacy horizontal top tab bar with a fixed 272px vertical navigation rail grounds the application in Apple macOS System Settings and pro-grade SaaS workflows (⌘1 through ⌘5 + ⌘K Command Palette).2.

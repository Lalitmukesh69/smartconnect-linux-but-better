# Smart Connect for Linux v0.2.0

Compiled release of **Smart Connect for Linux** (v0.2.0), bringing Motorola Smart Connect functionality to Linux desktops with modern GTK4/libadwaita architecture.

## Highlights
- **In-App Software Updates**: Check, download, and apply GitHub releases directly from within the app with atomic POSIX executable replacement.
- **2026 Apple Pro Dark Monochrome UI**: Full design system overhaul with unified tokens, frosted glass dialogs, and responsive layout styling.
- **Command Palette (`Ctrl+K`)**: Instant Spotlight-style keyboard launcher with quick navigation, feature actions, and developer profile cards.
- **Live Device Telemetry & Standby Caching**: Real-time battery indicator with charging states, Wi-Fi link quality, and cellular connection metrics, with persistent telemetry even during phone standby states.
- **Modern App Grid View**: Responsive 4-column icon grid view alongside the classic list stream for installed phone applications.
- **Rich System Tray & Status**: Hover tooltips with live device metrics and direct navigation shortcuts.
- **Redesigned Modals**: New "About Developer" modal with verified GitHub profile, sponsor links, and unified `DialogPrimitive` backdrop blur.

## What's Changed
- Implemented streaming downloader and atomic POSIX replacement in `gui/src/updater.rs`.
- Added Update settings in Preferences > General (check on startup, auto-download, channel).
- Redesigned Apps, Display, Cross Control, and Files screens with 2026 dark design tokens.
- Fixed phone overview telemetry display during standby and disconnected transitions.
- Updated desktop entry and generated multi-resolution rounded hicolor icons (16px to 512px).
- Clamped phone mockup proportions to 19.5:9 aspect ratio and aligned with page column.
- Added rich tray tooltips with live battery, signal, and quick launcher options.
- Streamlined README and migrated full technical specifications into `docs/`.

## Installation
If you are already running Smart Connect:
1. Open the App Menu (`...`) and click **Check for Updates…** (or press `Ctrl+K` and type `update`).
2. Click **Update Now**, then click **Restart Smart Connect**.

For fresh installation:
```sh
chmod +x smartconnect-gui
install -m755 smartconnect-gui ~/.local/bin/smartconnect-gui
```

Build from source:
```sh
git clone https://github.com/Lalitmukesh69/smartconnect-linux-but-better.git
cd smartconnect-linux-but-better
cargo build --release -p smartconnect-gui
```

## Requirements
- 64-bit Linux (x86_64), Wayland or X11, glibc >= 2.39, GTK4 >= 4.18, libadwaita >= 1.7.
- A running `smartconnectd` daemon service and helper binaries.
